# Go2 Robotics Challenge — Уровень 1 «Квалификация»

Отдельный пакет участника для **уровня 1**. Ты программируешь четвероногого робота **Unitree Go2**
в симуляторе **Webots R2025a**: робот реально ходит под физикой (штатная нейросетевая политика управления походкой), ты
пишешь только высокоуровневое управление. Полное описание уровня — **[TASK.md](TASK.md)**,
справочник API робота — **[API.md](API.md)**.

## Твоё решение — папка controllers/participant/
```
controllers/participant/          # вся папка: модули, YAML-конфиги, participant.py (точка входа)
```
Всё остальное (мир, робот, локомоция `go2_api`, судья) фиксировано и одинаково для всех.

## Быстрый старт

```bash
# 1 Подготовь окружение: скрипт создаст .venv, установит numpy и MNN, проверит ходьбу
./setup.sh                 # macOS / Linux
#   Windows (PowerShell): powershell -ExecutionPolicy Bypass -File .\setup.ps1

# 2 Установи Webots R2025a, см INSTALL.md

# 3 Запусти симуляцию
./run.sh                   # macOS / Linux
#   Windows: .\run.ps1
```

Откроется Webots с уровнем. Правь `participant.py`, сохраняй — Webots перезагрузит контроллер.
Счёт и события судьи — в консоли; итог — в `controllers/referee/result.json`.

Установка под Windows/Linux/macOS — **[INSTALL.md](INSTALL.md)**.

## Структура
```
common/                 # Общее ядро: робот, ходьба go2_api, судья и объекты
worlds/level1.wbt      # Пример мира, при оценке трасса генерируется и недоступна решению
config/level1.json     # Пример настроек трассы, при оценке карта другая и этот файл недоступен решению
```

> **Санкция.** Попытка решения читать `config/` или `worlds/` (файлы уровня) на зачётном прогоне
> ведёт к **обнулению результата** этого уровня. Файлы закрыты правами; сам факт обращения к ним
> фиксируется судейской системой проверки.

```
controllers/participant # Папка решения: модули, настройки Nav2 и SLAM, точка входа participant.py
controllers/referee     # Локальный судья: управление дверями, подсчёт баллов и result.json
setup.* run.* INSTALL.md API.md TASK.md
```
